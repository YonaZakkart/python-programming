# Python Programming - Estructuras de Datos

Repositorio que almacena el código y los ejercicios trabajados durante las sesiones de clase de Estructura de Datos. El contenido se encuentra organizado de forma cronológica por carpetas para facilitar la navegación y revisión de temas.

## Herramientas y Tecnologías

* **Lenguaje:** Python 3.x

---

## Requisitos Previos

Asegúrate de tener instalado Python 3 en tu sistema. 

Puedes verificarlo desde la terminal:

```bash
python --version
```

Si no lo tienes instalado:

#### Linux (Fedora/Debian/Ubuntu):

```bash
sudo dnf install python3      # Fedora
```
```bash
sudo apt install python3      # Debian/Ubuntu
```
#### macOS / Windows: 
Descarga el instalador oficial desde python.org.

---

## Instalación
Clona este repositorio en tu equipo local:

```bash
git clone https://github.com/YonaZakkart/python-programming.git
```
```bash
cd python-programming
```

---

## Ejecución
Navega a la carpeta correspondiente a la clase que deseas revisar y ejecuta el archivo .py:

```Bash
# Cambiar a la carpeta de la sesión deseada (ejemplo: Class01)
cd Class01
```
```bash
# Ejecutar el archivo deseado
python [archivo].py
```
